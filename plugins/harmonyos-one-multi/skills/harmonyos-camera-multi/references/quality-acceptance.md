# 相机 适配质量验收

用于将本领域的质量目标转化为具体检查项。按当前任务的目标等级、页面和设备范围选择适用项。

| 质量要求 | 领域落点与验收 |
|---|---|
| 基础可用：CORE-01 / STATE-01 / MEDIA-01 | 能完成拍摄或录像；折展、旋转、窗口变化后预览比例、方向和镜像正确，Session/Surface 与业务状态可恢复。按现有输出流和生命周期矩阵验证。 |
| 自适应优化：LAYOUT-01 / OVERLAY-01 / ACCESS-01 | 预览区域变化后 Surface 与控件几何一致；快门和模式栏可达，浮层不遮关键操作，焦点和字体设置不破坏交互。 |
| 场景增强：CAMERA-01 | 先核实设备支持，再验证双面预览或有业务价值的切镜；不能仅因枚举到多个相机就认定增强达标。 |

悬停页面分区仍由 UI 领域处理；本领域只负责相机链路、方向和预览区域。设备取证仍由调用方执行。没有运行证据时不把构建成功写成相机体验达标。
