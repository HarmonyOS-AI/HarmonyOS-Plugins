# 宽屏与横屏短高度适配

## 目标转换

当需求以具体设备表达时，先转换为可验证的 Web 条件：

| 设备描述 | H5 条件 |
| --- | --- |
| 展开态大屏横屏 | viewport 达到页面结构断点且 `orientation: landscape` |
| 方形展开屏 | 宽高接近且宽度足以承载多栏 |
| 直板机横屏 | 中等宽度、较短高度 |
| 系统分屏 | 任意设备上的实际 viewport/容器尺寸 |

设备名称只允许出现在需求说明和验证矩阵中，不能出现在 CSS 选择器、JS 条件或数据属性里。

## 横向空间如何使用

按信息架构选择一种主策略：

1. **重复布局**：卡片、商品、图片或列表项增加列数。
2. **分栏布局**：导航/目录、主内容、详情形成左右两栏或三栏。
3. **挪移布局**：底部导航移到侧边，操作栏从底部移到右侧。
4. **延展布局**：背景或非正文区域延展，正文保持合理行长。

不要同时放大字号、卡片、间距和图片来“填满”宽屏。宽屏价值通常来自更多信息或更短操作路径，而非整体缩放。

## 短高度约束

仅使用 `min-width` 的大屏规则可能误伤宽而短的窗口。逐项检查：

- 顶部栏、分类栏和底部导航是否叠加占用过多高度。
- 固定高度 hero、弹窗和表单是否超过可视高度。
- 关键按钮是否只能在无滚动容器之外访问。
- 粘性元素是否把正文压缩成过小区域。

```css
.page { display: grid; grid-template-columns: minmax(0, 1fr); }

@media (min-width: 840px) and (orientation: landscape) {
  .page { grid-template-columns: minmax(18rem, .9fr) minmax(24rem, 1.2fr); }
}

@media (min-width: 840px) and (orientation: landscape) and (max-height: 640px) {
  .hero { min-height: min(26rem, calc(100dvh - 10rem)); }
  .secondary-decoration { display: none; }
}
```

隐藏内容只能针对装饰或重复入口，不能隐藏核心信息和唯一操作。

## DOM 与状态连续性

- 优先用同一 DOM 改变 Grid/Flex 区域，保持阅读顺序和焦点顺序。
- 条件渲染多栏时，把业务状态提升到不会随布局分支销毁的位置。
- 布局变化不得重置路由、表单输入、媒体进度、选中项或滚动上下文。
- 导航挪移后保持相同可访问名称和激活状态。

## 验证矩阵

- 窄屏竖向基线。
- 断点前 1px、断点值、断点后 1px。
- 目标大屏横向窗口。
- 同宽度下的短高度窗口。
- 窗口连续跨越断点的过程。
- 200% 字体缩放和长标题。
