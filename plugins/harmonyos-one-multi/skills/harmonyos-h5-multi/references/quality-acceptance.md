# H5 适配质量验收

用于将本领域的质量目标转化为具体检查项。按当前任务的目标等级、页面和设备范围选择适用项。

| 质量要求 | 领域落点与验收 |
|---|---|
| 基础可用：CORE-01 / STATE-01 / INPUT-01 / MEDIA-01 | 同时检查 Web 容器与 layout/visual viewport；键盘打开后核心操作可达；resize、折展和旋转不整页 reload，不丢表单、滚动或播放进度。 |
| 自适应优化：LAYOUT-01 / NAV-01 / OVERLAY-01 | 按父容器重排；检查 REM 与宽屏布局的职责，包含嵌套 slot、Modal/Portal、宽短窗口和断点两侧；合理限宽可符合内容语义，不强制增列。 |
| 自适应优化：ACCESS-01 | DOM 阅读顺序、焦点顺序和字体放大后可操作；在目标 WebView 中验证，不以桌面浏览器结果代替宿主运行。 |
| 场景增强：FOLD-01 / DRAG-01 | 只有原生生产者和 Web 消费端能力明确时实现姿态或跨窗增强；需要核实桥接或平台能力，不能虚构接口。 |

先执行 H5-00，保留 H5_ONLY/ARKTS_ONLY/HYBRID 的所有权边界。缺少另一端应记录未验证或交接项，不能排除本来适用的门槛以提高等级。
