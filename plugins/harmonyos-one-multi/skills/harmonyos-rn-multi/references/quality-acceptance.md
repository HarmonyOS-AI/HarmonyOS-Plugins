# React Native 适配质量验收

用于将本领域的质量目标转化为具体检查项。按当前任务的目标等级、页面和设备范围选择适用项。

| 质量要求 | 领域落点与验收 |
|---|---|
| 基础可用：CORE-01 / STATE-01 / INPUT-01 / MEDIA-01 | 验证窗口→Dimensions→派生值→父约束→呈现链；折展不丢路由、输入、列表锚点，键盘与安全区变化后操作可达。 |
| 自适应优化：LAYOUT-01 / NAV-01 / OVERLAY-01 | 检查动态样式、FlatList 测量缓存、Modal/Portal 与原生 Surface 是否消费同轮约束；保持窄屏阅读顺序和导航身份。 |
| 自适应优化：ACCESS-01 | 按实际 RN/RNOH 版本验证字体缩放、语义、焦点和适用输入路径，不从 JS 属性存在推断原生实现通过。 |
| 场景增强：FOLD-01 / DRAG-01 / STYLUS-01 | 仅在业务需要且宿主/桥接能力可证实时实施。超出当前领域支持的专项列为能力缺口，不能以“JS 已实现”宣称完成。 |

复用 RN 场景、设备证据和组件能力路由；等级目标不意味着必须引入官方组件包。DIRECT/WRAP/FALLBACK 等能力判断继续以现有契约为准。
