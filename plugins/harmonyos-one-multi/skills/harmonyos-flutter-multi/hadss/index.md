# HADSS 路线索引

适用于已使用或明确允许引入 `hadss_adaptive_layout`、`hadss_avoid_area` 的工程。

先读 [setup.md](setup.md)，再按需读取与 Flutter 原生目录同名的能力文档。核心组件包括 `BreakpointManager`、`GridRow/GridCol`、`NavigationSplitContainer`、`SideBarContainer`、`AvoidAreaApi`、`FolderStack` 和 `FoldSplitContainer`。UX 截断类读取 [overflow-and-keyboard.md](overflow-and-keyboard.md) 与 [ux-fix-patterns.md](ux-fix-patterns.md)。

HADSS 状态用于布局，不得改写业务状态机。未确认包版本和 API 可用性前，不虚构依赖版本或方法签名。
