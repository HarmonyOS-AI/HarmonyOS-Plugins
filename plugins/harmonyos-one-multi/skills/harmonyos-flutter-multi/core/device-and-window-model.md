# 设备与窗口模型

断点面向当前可用窗口而非设备名称。至少记录逻辑宽高、方向、`viewInsets`、安全区、窗口模式、折叠状态、折痕区域和输入方式。

| 形态 | 主要风险 |
| --- | --- |
| 窄窗/外屏 | 键盘后高度不足、按钮和空态截断 |
| 近方形展开屏 | 导航和内容密度不匹配 |
| 极宽横屏 | 无意义限宽、底部导航未迁移 |
| 悬停态 | 内容跨折痕、展示区和操作区混乱 |
| 分屏/自由窗 | 动态缩放、窗口装饰遮挡 |
| 折展/旋转 | State、滚动或媒体进度丢失 |

局部布局优先使用 `LayoutBuilder`；全窗信息、安全区和键盘使用 `MediaQuery`。设备型号只用于复现记录，不参与布局分支。
